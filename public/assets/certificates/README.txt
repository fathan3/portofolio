FOLDER SERTIFIKAT
====================
Simpan file sertifikat Anda (format PDF, JPG, atau PNG) di dalam folder ini:
c:\laragon\www\porto\public\assets\certificates\

Contoh penamaan file:
- sertifikat-1.pdf
- sertifikat-2.pdf
- sertifikat-3.png
- sertifikat-4.pdf
- sertifikat-5.pdf

Setelah menyimpan file di sini, sesuaikan path "file" di file:
src/data/data.json -> bagian "certifications" -> "file": "/assets/certificates/sertifikat-1.pdf"
